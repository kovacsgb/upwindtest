Sod shock tube of the CIR numerical method
===========================================

This repository contain a numerical test implementation of the Courant-Isaacson-Rees method of partial differenital equations for the Sod shock problem.
The reults of this code was publised in the appendix C of [G.B. Kovács et al. (2025)](https://doi.org/10.1051/0004-6361/202452307).
